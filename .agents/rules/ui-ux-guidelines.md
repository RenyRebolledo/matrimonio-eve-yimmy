# Workspace UI/UX Design Directives: High-End Wedding & Editorial Standards

1. **Aesthetics Over MVP**: Never generate plain or generic web layouts. Every screen must evoke elegance, warmth, and luxury.
2. **Visual Hierarchy & Typography**: Always combine modern editorial serifs (e.g. *Cormorant Garamond*, *Italiana*) with clean sans-serifs (*Plus Jakarta Sans*, *Outfit*) and romantic calligraphy accents (*Alex Brush*, *Pinyon Script*).
3. **Color Palette Cohesion**: Use bespoke, soft natural palettes (warm ivory, muted blush, eucalyptus sage, champagne gold accents) with subtle drop shadows and organic glassmorphism.
4. **Delightful Micro-Animations**: Smooth reveal transitions, interactive wax seal or envelope opening moments, interactive RSVP, and seamless mobile responsiveness.
